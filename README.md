# Observer Pet / 剧情旁观小团子

一个住在 SillyTavern 页面上的小小旁观聊天伙伴。它会读取你授权的最近剧情，在独立小窗里陪你吐槽、分析和接梗，不会写入角色剧情。

## 初版功能

- 可拖动、会眨眼的蓝色小团子图标。
- 小团子会在本地根据每次对话切换大笑、哭哭、委屈、可爱、坏笑、生气、无语等表情，维持 30 秒后恢复默认偷笑脸；不会要求模型额外输出情绪标签，也不增加 API 调用。
- 点击图标打开可拖动的独立聊天窗；电脑端可调整窗口大小。
- 通过 SillyTavern Connection Manager 选择独立 API / 模型，不另行保存密钥。
- 明确选择连接配置后会锁定该 API / 模型，不随酒馆当前配置切换；扩展不会发送该配置绑定的酒馆预设。
- 可将剧情分成“较早摘要 + 最近完整正文”：正文数量可设为 0–100，旧摘要可限制条数或一直回溯到第一条匹配摘要。
- 摘要标签可在设置中自行修改；兼容 `<meow_FM>...</meow_FM>` 和只有起始标签、摘要延续到消息末尾的格式。
- 可设置旁观对话历史数、角色卡、用户人设、作者注、输出长度和温度。
- 自带按酒馆聊天隔离的滚动长期记忆：默认保留最近 20 条你与小团子的完整对话，较早消息每积满 20 条自动压缩一次。
- 长期记忆由小团子使用第一人称整理，重点保存你的偏好、双方形成的判断、小团子的立场、约定与未完话题；剧情只保留理解这些观点所需的少量人物名和事件。
- 可在设置页查看、修改、立即整理或清空长期记忆；自动整理失败不会删除原始旁观聊天。
- 支持简短／自然／不限三档回复长度偏好；模型生成预算同时覆盖内部思考与正文，思考模型默认使用 4096 tokens，避免正文被预算截断。
- 旁观消息使用 SillyTavern 的安全 Markdown 渲染，支持加粗、列表、行内代码等常见格式。
- 可在发送前预览小团子会看到的内容。
- 旁观对话与长期记忆由小团子全局共用；更换角色卡或聊天不会换一只新团子，眼前剧情仍跟随当前聊天。界面位置仅保存在当前设备。
- 旁观回复使用整包返回，避开部分 Gemini 兼容渠道流式传输提前结束、只留下半句话的问题；等待期间仍可中途停止。
- 轻点任意旁观消息可展开“复制 / 删除”，操作不会影响酒馆剧情正文。
- 设置页可一键从 GitHub 检查并更新，能自动识别本用户或全局安装；更新不会删除小团子的全局旁观记录。

## 安装

在 SillyTavern 的扩展页选择“安装扩展”，粘贴：

```text
https://github.com/sugar8482/sillytavern-observer-pet
```

本地测试时，也可将整个目录放入：

```text
SillyTavern/data/<用户>/extensions/sillytavern-observer-pet/
```

然后重启 SillyTavern 或重载页面。

## API 配置

1. 先在 SillyTavern 的 **Connection Manager** 中建立一个可用连接配置。
2. 点击小团子，再点右上角齿轮。
3. 选择一个连接配置，或让它跟随酒馆当前配置。

扩展不保存 API Key，也不会把旁观者回复写进角色对话。普通回复和长期记忆整理都会复用你选定的连接配置，但不会读取该配置绑定的酒馆预设。
